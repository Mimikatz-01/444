# rhcopy — копи-бот трейдеров FOMO: Robinhood Chain, Ethereum и Solana

Следит за кошельками выбранных трейдеров. Когда трейдер заходит в новый токен, бот прогоняет сигнал через фильтры, покупает на USDG и сам выходит по твоей стратегии.

Покупки идут через Relay — тем же путём, каким их делает сам FOMO. Поэтому маршрут находится даже для токенов, запущенных минуту назад. Издержки на сделку: сервисная комиссия Relay около 0.15% плюс газ около цента. У copyfomo это 2% плюс газ.

## Как устроено

```
кошельки трейдеров ── eth_getLogs (Transfer, все кошельки одним запросом, раз в секунду)
      │  первая покупка токена (баланс блоком раньше = 0), пришёл от контракта
      ▼
фильтры (дешёвые сначала):
  пауза · уже держим · раньше рагнул · кулдаун · лимит позиций · свежесть · токенизированные акции
  настоящий свап, а не аирдроп · plant: сделку оплатил кто-то другой в ETH
  ПРОВЕНАНС: запись Relay — referrer "fomo", депозит с Solana, подписант = Solana-кошелёк трейдера
  DexScreener: ликвидность, капа, возраст пула, соотношение продаж к покупкам
  котировка Relay: догон цены трейдера, влияние на цену, газ, потеря на круге «купил-продал»
      ▼
покупка (paper: реальная котировка, сделка не отправляется)
      ▼
выходы: лесенка TP · выходы по времени · стоп · breakeven · выход вслед за трейдером · max hold
```

**Подставные покупки** — главная ловушка копи-ботов. Скамер покупает свою монету прямо на кошелёк известного трейдера, и в сети это выглядит как его собственная покупка. Отличить можно только по одному признаку: депозит на Solana подписан личным Solana-кошельком трейдера. Подделать эту подпись нельзя.

Relay индексирует сделку через 5–7 секунд после блока. Поэтому бот ждёт запись около 1.5 секунды, а если её ещё нет — покупает и перепроверяет каждую секунду. Если сделка окажется подставной, бот сразу сливает позицию.

## Установка на VPS (Ubuntu)

```bash
sudo mkdir -p /opt/rhcopy && sudo chown $USER /opt/rhcopy
cd /opt/rhcopy          # распакуй сюда архив
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp config.example.yaml config.yaml
cp .env.example .env    # заполни TELEGRAM_BOT_TOKEN; PRIVATE_KEY нужен только для live
```

**Трейдеры.** В copyfomo сделай `/find <ник>` — он покажет EVM-адрес трейдера и его Solana-адрес. Впиши их в `config.yaml`, в секцию `wallets`. Можно добавить и из Telegram: `/add 0xАДРЕС Ник`. Если Solana-адрес не указан, бот попробует найти его сам через `/learnpair Ник`: берётся подписант большинства FOMO-покупок трейдера.

**Telegram.** Создай бота через @BotFather, положи токен в `.env` и запусти бота. В логе появится код — отправь своему боту `/start КОД`. После этого бот отвечает только тебе.

```bash
python main.py run                        # запуск (paper, пока live: false)
python main.py route <token> 15           # проверка токена без сделки: ликвидность, котировки, круг
python main.py learnpair <0xадрес>        # найти Solana-кошелёк трейдера
python main.py status                     # все пользователи: режим, кэш, позиции, PnL
```

Как сервис: скопируй `deploy/rhcopy.service` в `/etc/systemd/system/`, затем `systemctl enable --now rhcopy`, логи — `journalctl -fu rhcopy`.

## Сначала paper, и сразу A/B

Paper-режим берёт реальные котировки Relay, но ничего не отправляет. Запусти два инстанса с разными схемами выхода на одних и тех же трейдерах. Через 1–2 недели сравни `/stats`.

```bash
python main.py run --config config.ladder.yaml --db data/ladder.db    # exits.mode: ladder
python main.py run --config config.timed.yaml  --db data/timed.db     # exits.mode: timed
```

У каждого инстанса должен быть свой Telegram-бот (свой токен в отдельном `--env`) или выключенный Telegram.

## Переход на живые деньги

1. 👛 Кошелёк → 🔑 Создать кошелёк. Бот покажет адрес и сразу предложит сохранить ключ («🔐 Показать ключ»). Владелец вместо этого может положить ключ своего свежего кошелька в `.env`, в строку `PRIVATE_KEY`.
2. Пополни кошелёк USDG — строго `0x5fc5360D0400a0Fd4f2af552ADD042D716F1d168` (6 знаков после запятой; остальные «USDG» в сети — подделки) — и ETH на газ: 0.005 ETH хватает на сотни транзакций. Удобнее всего через relay.link.
3. В настройках поставь тикет $2, затем 👛 Кошелёк → 🔴 Включить LIVE. Прогони несколько реальных сделок и сверь их в эксплорере.
4. Только после этого поднимай тикет. Вернуться в paper можно той же кнопкой в любой момент.

Бот один раз даёт разрешение Relay на списание USDG, а после каждой покупки — на сам токен. Благодаря этому каждый выход — одна транзакция.

## Управление в Telegram — кнопками

После привязки (`/start КОД` из лога) внизу экрана появятся четыре постоянные кнопки: **📊 Меню · 💼 Позиции · 👥 Трейдеры · ⚙️ Настройки**. Дальше всё делается нажатиями, как в copyfomo, и меню обновляется в том же сообщении.

- **Меню** — режим (paper/live), капитал, кэш, открытые позиции, PnL, пауза и продолжение работы.
- **Позиции** — карточка каждой позиции: вложено, сколько стоит сейчас, PnL, пик, сработавшие TP, стоп. Кнопки: «продать 50%», «продать всё» (с подтверждением) и ссылка на DexScreener.
- **Трейдеры** — добавить (прислать `0xАДРЕС Ник`), включить или выключить копирование, свой тикет на трейдера, найти Solana-кошелёк, удалить. У каждого своя статистика.
- **Настройки** — размер (тикет, число позиций, доля банка), выходы (режим лесенка/таймер/оба, готовые лесенки и таймеры или свои — вводятся как `50:50 300:25`, стоп, безубыток, выход вслед за трейдером, максимальное время удержания), фильтры (догон, ликвидность, минимальная покупка трейдера, возраст пула, влияние на цену, защита от подставных), уведомления о пропущенных сигналах.
- **Статистика** — результат по каждому трейдеру и главные причины пропуска сигналов: по ним видно, что режут фильтры.

Сообщения о покупке и продаже приходят с кнопками «📄 Позиция» и «🔴 Продать всё».

**Пропущенные сигналы — как в copyfomo.** На каждый сигнал, который отсеял фильтр, приходит сообщение: монета, сеть, трейдер, на сколько он купил, капа и причина с цифрами — например, «наша цена выше цены трейдера на +31% (лимит 25%)». Под ним есть кнопки DexScreener и «🔕 Не присылать такие» — она выключает одну причину. Включить её обратно можно в ⚙️ Настройки → 🔔 Уведомления. Раздачи токенов (спам в кошельки трейдеров) бот не присылает никогда.

**📈 Статистика → ⏭ Пропущенные монеты** показывает последние пропуски и то, что монета сделала после: выросла или упала. По этому списку видно, режут фильтры прибыль или спасают от слива.

Текстовые команды тоже работают — список в `/help`.

## Ethereum

Трейдеры FOMO торгуют и в Ethereum, и у них там тот же EVM-адрес, что в Robinhood Chain. Поэтому отдельно добавлять трейдеров не нужно: бот следит за ними в обеих сетях сразу. Логика та же, что в Robinhood:
- **Проверка подлинности** — через запись Relay: подписал ли сделку Solana-кошелёк самого трейдера.
- **Фильтры** те же, что в Robinhood.
- **Сделки** идут через Relay за USDC.

**Без ключей.** По умолчанию бот работает через публичные узлы (drpc, mevblocker, blastapi) и при ошибке сам переключается на следующий. Для надёжности можно добавить свой RPC в `.env`, строку `ETH_RPC_URL` — например, бесплатный ключ Alchemy. Он будет использоваться первым.

**Кошелёк** тот же EVM-кошелёк, что в Robinhood: один адрес и один ключ, но балансы в каждой сети свои. 👛 Кошельки → 🔷 Ethereum: там балансы, вывод USDC и ETH и отдельный переключатель LIVE. Пополнять нужно USDC в сети Ethereum (`0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48`) на сделки и ETH на газ — от 0.002 ETH.

**Газ** сейчас дешёвый, но в Ethereum он всё равно дороже, чем в Robinhood. Поэтому лимит газа здесь 3% тикета, а тикет лучше брать от $25. Выключить сеть можно в ⚙️ Настройки → 🌐 Сети.

## Solana

Бот копирует сделки трейдеров и в Solana. У трейдера FOMO два кошелька: EVM-кошелёк в Robinhood Chain и Solana-кошелёк. Solana-кошелёк бот уже знает — это та самая «пара», по которой он проверяет подлинность покупок. Поэтому как только у трейдера найдена пара, бот следит за ним в обеих сетях сам. Можно добавить и трейдера только из Solana: в «➕ Добавить трейдера» пришли его Solana-адрес и ник.

**Как это работает:**
- **Слежение.** Одно WebSocket-соединение и подписка на каждый кошелёк. Если сокет недоступен, бот переходит на опрос раз в несколько секунд.
- **Проверка подлинности.** Покупка засчитывается, только если трейдер сам подписал транзакцию — подделать это нельзя. Токены, которые ему просто прислали, бот игнорирует.
- **Защита от ловушек.** Бот пропускает токены, которые создатель может заморозить, и токены с опасными расширениями Token-2022: комиссия за перевод, хуки, постоянный делегат.
- **Сделки** идут через Jupiter (Swap API V2: `/order` + `/execute`). Jupiter ищет маршрут по всем DEX (pump.fun, PumpSwap, Raydium, Meteora…), сам ставит приоритетную комиссию и доводит транзакцию до блока. Его комиссия — 0.1% со сделки.
- **Залог за токен-аккаунт** (около 0.002 SOL ≈ $0.25) бот возвращает: после полной продажи он закрывает пустой аккаунт.

**Настройка:**
1. `pip install -r requirements.txt` — добавились библиотеки для Solana.
2. Желательно бесплатные ключи:
   - helius.dev → Dashboard → API key → в `.env` строку `HELIUS_API_KEY=`. Это даёт надёжный RPC и WebSocket.
   - developers.jup.ag → ключ → `JUPITER_API_KEY=`. С ним 1 запрос в секунду вместо 0.5.

   Без ключей всё работает на бесплатных публичных узлах, но медленнее и менее надёжно.
3. 👛 Кошельки → 🟣 Solana → 🔑 Создать Solana-кошелёк. Пополнить: USDC в сети Solana (токен `EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v`) — на сделки, и около 0.1 SOL — на комиссии и залоги. С биржи выводи, выбрав сеть Solana.
4. LIVE в Solana включается отдельно от Robinhood — там же, в Solana-кошельке. Paper-банк общий для обеих сетей.
5. В какой сети копировать, каждый выбирает сам: ⚙️ Настройки → 🌐 Сети.

**Расходы:** комиссия сети и приоритет — обычно центы за сделку; Jupiter берёт 0.1%; залог за токен-аккаунт возвращается. RPC Helius на бесплатном тарифе стоит $0.

## Несколько пользователей в одном боте

Один бот и один сервер могут обслуживать нескольких людей. У каждого свои трейдеры, настройки, позиции, paper-банк и собственный кошелёк. Следит за сетью один общий процесс: если двое копируют одного трейдера, каждый получает сигнал по своим настройкам. Порядок покупок чередуется, чтобы никто не был всегда вторым.

- **Владелец** — тот, кто привязал бота кодом из лога (`/start КОД`). Ему достаются трейдеры из `config.yaml` и кошелёк из `.env`, если он задан.
- **Пригласить друга:** 📊 Меню → 👤 Пользователи → ➕ Пригласить. Бот выдаст строку вида `/start a1b2c3d4` — код одноразовый и действует 24 часа. Друг находит твоего бота в Telegram по его @username и отправляет ему эту строку.
- **Отключить пользователя** можно там же. Его открытые позиции доиграют по его выходам, новых покупок не будет.
- **Кошельки** (👛 в меню) у каждого свои, в Robinhood Chain и в Solana: бот создаёт его сам, показывает адрес для пополнения и балансы, умеет выводить USDG и ETH на внешний адрес. Приватный ключ показывается в сообщении, которое удаляется через 60 секунд и защищено от пересылки. Переход на LIVE каждый включает сам, с подтверждением.
- **Доверие.** Ключи кошельков хранятся на сервере в `data/bot.db`, поэтому владелец сервера технически имеет к ним доступ. Это нормально для друзей, но держать на ботовых кошельках стоит только рабочие суммы. Закрой базу от чужих глаз: `chmod 700 data`.

Обновление со старой однопользовательской версии происходит автоматически: при первом запуске всё, что было (трейдеры, позиции, настройки, привязка Telegram), становится данными владельца. Перед обновлением сделай копию: `cp data/bot.db data/bot.db.bak`.

## Журнал

`data/bot.db` (SQLite) хранит каждый сигнал и причину решения по нему, плюс все позиции и сделки. По нему настраиваются фильтры — на фактах, а не по памяти.

```sql
SELECT reason, count(*) FROM signals WHERE decision='skipped' GROUP BY reason ORDER BY 2 DESC;
SELECT label, count(*), sum(realized_usd-cost_usd-gas_usd) FROM positions WHERE status!='open' GROUP BY label;
```

## Ограничения — честно

- Ты всегда входишь **после** трейдера. На этой сети нет мемпула, так что обогнать его нельзя. Детект занимает 1–2 секунды, плюс время на фильтры и котировки.
- Paper-котировка — это не исполнение. Реальная цена может отличаться на резких свечах. Газ в paper-режиме считается по верхней оценке Relay, поэтому paper-PnL слегка пессимистичен.
- DexScreener не сразу видит новые пулы: токены младше примерно минуты пропускаются (`require_market_data`).
- Публичный RPC иногда отвечает 429. Для стабильности поставь свой `RPC_URL`.
- Код не проходил аудит. Ключ в `.env` управляет деньгами — держи на этом кошельке только рабочую сумму и регулярно выводи прибыль.
