# Changelog

## Источники сигналов, сети BNB/Base, совпадения и фильтр инсайдеров

Добавлено поверх версии с Robinhood Chain, Ethereum и Solana. База и `config.yaml` от
предыдущей версии открываются без изменений (миграции аддитивные).

### Модель источника сигнала
- У трейдеров, позиций и сигналов появилась метка `source` (откуда импортирован трейдер /
  тип входа). Экран **📈 Статистика → 📡 По источникам**: закрытые сделки по типу входа
  (кошелёк / совпадение) и по метке импорта (вручную / FOMO / GMGN / kolscan / MadeOnSol / вставка).
- Докупки трейдера (монета, которой у него уже был баланс) больше не игнорируются молча:
  приходит `not_first_buy` с суммой докупки и кнопкой мьюта. По докупкам бот не покупает.

### Сети BNB Chain и Base
- Копирование в BNB Chain (chain id 56) и Base (8453) по той же схеме, что Ethereum.
- Учёт точности стейблкоина: в BNB Chain USDT имеет 18 знаков (поле `EvmNet.usd_decimals`).
- Единое поле `users.live_chains` (JSON-список) вместо `live` / `sol_live` / `eth_live`
  (одноразовая миграция). LIVE включается в каждой сети отдельно.
- Экраны кошельков BNB Chain и Base, переключатели в 🌐 Сети, метки `BSC` / `BASE`.
- `.env`: `BSC_RPC_URL`, `BASE_RPC_URL`.

### Импорт кошельков и масштаб
- **📥 Импорт кошельков**: вставка списка/CSV/таблицы/ссылок (GMGN, kolscan, solscan,
  etherscan, MadeOnSol) с предпросмотром и подтверждением. GMGN и kolscan не скрапятся.
- **🏆 Топ KOL из MadeOnSol**: лидерборд KOL через официальный API с фильтрами (нужен
  `MADEONSOL_API_KEY`; без ключа — «нужен ключ»).
- Лимит `sources.max_traders_per_user` (200).
- Масштаб: в EVM адреса опрашиваются пачками по 100, в Solana слежение раздаётся на
  несколько WebSocket-соединений (`solana.ws_wallets_per_conn`, по умолчанию 50).

### Совпадения (confluence)
- `gates.confluence_min` (1 = выкл / 2 / 3) и `gates.confluence_window_min` (5 / 10 / 30).
- Вход только когда несколько независимых кошельков купили монету за окно; независимость —
  по пересечению Solana-пар. Пропуск `no_confluence`, если совпадения не было.

### Фильтр инсайдеров
- Модуль `rhcopy/risk.py`: доля пачки на запуске, доля создателя, концентрация топ-10,
  кошельки вокруг создателя, прошлые раги. Источники: MadeOnSol + встроенные эвристики
  (создатель pump.fun из bonding curve; создатель EVM через Etherscan V2).
- `gates.insider_check` (off / soft / strict) и пороги. Проверка в `judge()` после рынка до
  котировок, бюджет 3 с, кэш `token_risk` (TTL 30 мин). Строка риска в карточке позиции.
- `.env`: `MADEONSOL_API_KEY`, `ETHERSCAN_API_KEY`.

### Тесты
- `tests/`: forced-facts сделки по всем сетям, обход кнопок, миграция старой базы, импорт,
  совпадения, инсайдер-фильтр. Офлайн-прогон `python -m pytest -q` зелёный.
